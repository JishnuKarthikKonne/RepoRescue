# 3-minute demo (planned)
1. Human posts a checkout bug report in `#reporescue`.
2. Triage agent summarizes/classifies and delegates.
3. Reproducer agent runs a minimal failing test and posts exact output.
4. Fix agent creates an isolated patch.
5. Verifier runs tests and posts evidence.
6. Human reviews diff and explicitly approves PR creation.
7. Show task state/history and README setup.

Use a disposable repository and a known seeded bug. Clearly label any prerecorded fallback.
